Logo Usage

04
On Dark ✓
On Sand ✓
On Magenta ✓
On Terracotta ✓

✓ Do
  • Use on dark, sand, magenta, or terracotta backgrounds
  • Keep minimum clear space equal to the logo height on all sides
  • Use the full square icon with rounded corners
  • Pair with Playfair Display wordmark beside it
✗ Don't
  • Stretch, warp, or rotate the icon
  • Place on busy photographic backgrounds without a dark overlay
  • Recolor the icon in non-brand colors
  • Use at sizes smaller than 24×24px
