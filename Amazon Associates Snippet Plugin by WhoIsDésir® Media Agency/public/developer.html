Display Amazon Products with Product Links

Amazon's own link builder generates HTML you can paste straight into WordPress — images, prices-as-text, and affiliate tracking included. No Creators API access needed, so it works while your account is still earning toward eligibility.

Show Me How Developer Notes

Step 1 — Get Your Product Links Code

Amazon retired its old JavaScript widgets in 2022. The current replacement is the Product Links tool in Associates Central, which outputs plain HTML you can embed anywhere.

Step 1.1

Open the Product Links tool

  1. Sign in to Amazon Associates Central (affiliate-program.amazon.com).
  2. In the top menu, go to Product Linking → Product Links.
Step 1.2

Find a product

  1. Search by product name, keyword, or paste an ASIN (e.g. B08N5WRWNW).
  2. Click the product you want to promote.
Step 1.3

Choose a format and copy the code

  1. Pick a format:
    • Text — a plain affiliate link.
    • Image — the product photo linked to Amazon.
    • Text and Image — the full box: photo + title + price + your affiliate tag.
  2. Click Get Link.
  3. Click Copy Code — the generated HTML is now on your clipboard.
Faster shortcut — SiteStripe: While signed in, open any product page on Amazon. The SiteStripe bar at the top has Text, Image, and Text and Image buttons that generate the same code instantly, without visiting Associates Central.
Important: the generated HTML contains your unique tag= tracking parameter. Never strip or alter it — that's how Amazon credits your sales.

Step 2 — Add It to WordPress

Choose the placement that fits your site. All four options work with the same copied code.

Page / Post Editor

Inside an article

In the block editor, click the + icon, search for Custom HTML, paste the code, and publish. Renders inline with your content.

Appearance → Widgets

Sidebar / footer widget

Add a Custom HTML widget to any widget area (sidebar, footer, homepage) and paste the code into it. Shows site-wide.

Theme Template

Directly in PHP

Developers: paste the HTML inside any theme file (e.g. single.php). Use a PHP snippet to conditionally render it per-post.

Plugin Shortcode

Plugin-native approach

Once your Creators API account is eligible, replace static code with the plugin's [amazon_box], [amazon_link] or [amazon_button] shortcodes for live prices and automatic updates.

Recommended path for new sites: use [amazon_link] and [amazon_button] shortcodes now — they render working affiliate links with zero API access. Add Product Links boxes for visual content today, then swap them for [amazon_box] when the Creators API unlocks.

Developer Notes

What Product Links are (and aren't) under the hood.

  • Static HTML, no JavaScript. The code is an anchor tag (and an <img> for image formats). No API keys, no credentials, no rate limits.
  • Works regardless of Creators API eligibility. Product Links only need your Associates account — not the 10-sales threshold. This is the fastest way to monetize while you qualify.
  • Not live-updating. A Product Link is a snapshot — price and availability only change when you regenerate it. For live data, use the plugin shortcodes with an eligible Creators API account.
  • Every link embeds your tracking tag. Keep tag=yourname-20 intact or the click won't be attributed to you.
  • Compliance is automatic-ish. Amazon requires a disclosure. The plugin's product cards add one automatically; if you paste raw HTML, add your own “As an Amazon Associate I earn from qualifying purchases.” line nearby.

Enfold — Add a Table with Rows & Columns in a Post

Add the snippet code (or any HTML table) directly inside a blog post, not a page. Enfold keeps posts in the classic editor by default, so this is the fastest, most reliable method.

Step 1 — Open the post and switch to the Text tab

Edit the post. In the editor toolbar above the content area, click the Text tab (next to Visual). This reveals the raw HTML for the post.

Step 2 — Paste the table HTML where you want it

Place your cursor where the table should appear, then paste the code below. Every <tr> is a new row and every <td> is a column inside that row. Swap the example text for your affiliate links.

table-paste.html
<table>
        <thead>
            <tr>
                <th>Product</th>
                <th>Rating</th>
                <th>Price</th>
                <th>Buy Link</th>
            </tr>
        </thead>
        <tbody>
            <tr>
                <td>Echo Dot (5th Gen)</td>
                <td>4.7 / 5</td>
                <td>$49.99</td>
                <td><a href="https://www.amazon.com/dp/B09B8V1LZ3?tag=YOURTAG-20" target="_blank" rel="nofollow noopener">View on Amazon</a></td>
            </tr>
            <tr>
                <td>Kindle Paperwhite</td>
                <td>4.8 / 5</td>
                <td>$139.99</td>
                <td><a href="https://www.amazon.com/dp/B08KTZ8249?tag=YOURTAG-20" target="_blank" rel="nofollow noopener">View on Amazon</a></td>
            </tr>
            <tr>
                <td>Fire TV Stick 4K Max</td>
                <td>4.6 / 5</td>
                <td>$54.99</td>
                <td><a href="https://www.amazon.com/dp/B08MQZXN1X?tag=YOURTAG-20" target="_blank" rel="nofollow noopener">View on Amazon</a></td>
            </tr>
        </tbody>
    </table>

Step 3 — Save the post

Switch back to the Visual tab to check the layout, then click Update. Enfold's theme CSS styles plain <table> tags automatically (striped rows, borders), so no extra styling is needed.

Using Enfold's Advanced Layout Builder on this post? If the post editor shows the blue Advanced Layout Editor button, use the Text Block element instead: drag it in, paste the same table HTML into the element's text area, and Save. Or use Enfold's built-in Table element for a point-and-click rows-and-columns grid.

Enfold — Build a Page with the Advanced Layout

Enfold's Advanced Layout Builder (ALB) is a drag-and-drop grid for pages. Combine rows, columns, color sections, and content elements to build a polished, fully designed page without touching CSS.

Step 1 — Create the page and launch the builder

Go to Pages → Add New. In the top bar of the editor, click Advanced Layout Editor (the ALB toggle). Enfold switches the page into the visual drag-and-drop builder.

Step 2 — Add columns for your layout

Drag the Columns element onto the canvas and choose how to split the row — 1/2 + 1/2, 1/3 + 1/3 + 1/3, or 1/4 × 4. Each column becomes a container you can drop content into. These columns respond to the theme's grid, so they stay responsive on mobile.

Step 3 — Drop in the content elements

  • Text Block — paste plain HTML, including the Product Links snippet or an HTML table.
  • Table — Enfold's own rows-and-columns editor; add/remove rows and columns with a click.
  • Heading — section titles and sub-headlines.
  • Button — styled call-to-action buttons that link anywhere.
  • Image / Featured Image — product photos with optional link and caption.

Step 4 — Add full-width bands with Color Section

Wrap any group of columns in a Color Section to create a full-bleed colored band (background color, image, or gradient) with your chosen text color. Stack several sections to build a landing page: hero → product grid → comparison table → final call-to-action.

Step 5 — Save the page

Click the Save button in the builder toolbar, then Preview to check mobile and desktop. You cannot mix the ALB and the classic editor on the same page — pick the Advanced Layout Editor for pages and keep the classic Text tab for posts.

Product Links in ALB: copy your snippet from the generator, drop a Text Block into a column, paste the code, and save. The box renders as designed — use a Color Section or a 2-column grid next to a product image for a professional affiliate page.
