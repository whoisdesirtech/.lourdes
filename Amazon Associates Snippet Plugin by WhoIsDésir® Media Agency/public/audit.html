Executive Summary
1

What you built

A tested, dependency-optional Amazon Creators API WordPress plugin: OAuth 2.0 (v2/v3), dual SDK/HTTP transports with auto token-recovery, response normalizer, 5 shortcodes, global PHP helpers, admin generator + API tester, transient caching, FTC compliance — plus a marketing site with Vercel + Postgres lead capture.

2

Category

Affiliate product-display & snippet toolkit for WordPress — with a provider-agnostic data layer already half-built (normalizer, facade, transport abstraction, dependency injection).

3

Competitive gap

AAWP owns Amazon display, Lasso owns link management, Content Egg owns breadth-but-clunk. Nobody offers a modern provider-agnostic normalized data layer with blocks + click analytics. That gap is the opportunity.

4

Key 2026 fact

Amazon retired PA-API on May 15, 2026. The Creators API is the only product-data path — your migration puts you ahead of competitors still scrambling.

5

Recommended direction

Option B — a multi-network affiliate platform (Walmart, eBay, AliExpress) built on the existing provider abstraction, with comparison tables, Gutenberg blocks, Keepa price history, and click tracking.

6

Architecture

Formalize a ProductProvider interface + registry behind a single AA_Product_Api facade — Amazon first, Walmart/eBay/AliExpress next.

API Ecosystem Preview
1

Amazon Creators API Official

OAuth 2.0 client-credentials (v2 Cognito / v3 LwA). 1 req/s base. 10 qualifying sales/30 days for eligibility. Replaced PA-API May 15, 2026.

2

Walmart Content Provider API Official

Real-time Product Feed API added May 2026. Commission 1–4%. Best second provider for North America via Impact.

3

eBay Browse API + EPN Official

OAuth 2.0 app tokens, free. Great for used/refurbished and curated niches.

4

AliExpress Affiliate API Official

Strongest for international / lower-AOV niches via the Open Platform.

5

Keepa Integrate

Amazon price history, drops, BSR. ~€19–59/mo. Powers the price-trend sparkline feature publishers pay for.

6

Rule of thumb Don't scrape

Never scrape when an official API or affiliate feed exists — official sources cover ~95% of realistic use cases.
